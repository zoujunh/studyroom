# 408 刷卡 · 备考工作台（PWA）

计算机考研 408 的一站式备考应用。**内容按考纲系统覆盖，功能闭环到「知道自己哪里不会」。**

| 模块 | 说明 |
| --- | --- |
| **刷卡背诵** | 一张卡一个问题，翻面看结构化答案，按「不会 / 模糊 / 会了」自评，FSRS 间隔重复调度 |
| **题库与错题本** | 单选 / 判断、即时判分与解析、错因归因、连续答对自动移出、按分值比例组卷模考 |
| **综合应用题** | 408 的 70 分大头：先自己做，再按评分点逐条自评，实时算分并汇总固定丢分位置 |
| **可视化演示** | 10 个算法动画（排序 / 置换 / 调度 / 银行家 / Cache / 流水线 / KMP / 分片 / TCP / 图遍历），可单步回看 |
| **冲刺模式** | 按考试日期倒排每日新卡量、完成预测、考前还能过几轮 |
| **全局搜索** | 在全部卡片、选择题、大题里全文检索，就地看答案 |

## 关键设计

### 刷卡：FSRS 调度

**为什么默认目标保持率 95% 而不是 90%？** 实测连续评「会了」的间隔推进：

| 目标保持率 | 间隔推进（天） |
| --- | --- |
| 90% | 0 → 2 → 13 → 56 → 196 |
| **95%（默认）** | **0 → 1 → 4 → 8 → 22 → 45** |

90% 下一次复习就跳到 13 天，对 92 天冲刺太稀疏；`maxIntervalDays()` 还会把任何一张卡的最长间隔压到考前剩余天数以内。

**评分流程**：点「不会 / 模糊 / 会了」→ 立刻落库、**自动把答案亮出来**、底部变成「下一题」；
**同一轮里每张卡只出现一次**，不会把刚才不会的卡又抬回来。想改判按 `Z` 撤销，专项状态也会一起回滚。
三个按钮上的小字是 FSRS 算出的「下次什么时候再见」。
键盘：`空格` 翻面/下一题、`1/2/3` 评分、`Z` 撤销、`Esc` 退出。

**进度条**：分母固定为「本轮计划张数」，不再变化（同一轮不重复出卡）。

**三态口径**：没学过（`reps === 0`）/ 学习中 / 已掌握（`state === Review` 且稳定度 ≥ 14 天）。

### 复习专项（卡片级薄弱项）

刷卡时评「**不会 / 模糊**」的卡片自动进「复习专项」，评「会了」**连续两次自动移出**——
和选择题错题本是同一套状态机（`lib/focus.ts`）。

- 入口：首页快捷入口、首页统计行、统计页都能看到待攻克数量
- 专项页：按错误次数从多到少、按科目筛选、展开直接看答案、可手动移出
- 「全部刷一遍」→ 会话只出专项里的卡
- 与 FSRS 的分工：**FSRS 决定「什么时候该复习」，专项记录「这一轮我明确没掌握的卡」**

### 题库与错题本

- 判分：选项集合完全一致才算对；**答错**进错题本、`wrongCount++`；**答对**累计 `correctStreak`，
  **连续答对 2 次自动移出**；错题重做按错误次数从多到少排；
- 错因归因：概念不清 / 计算失误 / 审题错误 / 记忆模糊 / 时间不够 / 手滑——
  错题本与统计页汇总成分布图，「概念不清」多说明该回去刷卡，「计算失误」多则要练手算速度；
- 模考：按分值比例组卷（数据结构 6 / 组成 5 / 操作系统 5 / 网络 4 = 20 题），限时 30 分钟，
  考试中不给对错，交卷后按每题 2 分给出总分、分科明细与错题清单。

### 综合应用题（评分点自评）

没有 AI 批改，改用**评分点自评**：自己先做 → 点「看评分点」→ 逐条对照参考答案勾选 → 实时算分 →
报告列出漏掉的每个点；列表页长期汇总「**最常漏的评分点**」——这是你固定的丢分位置，比总分更有指导价值。

### 可视化引擎

每个动画只是一段**纯函数**（输入 → 步骤数组），引擎负责播放/单步/回看/变速/URL 分享：

```ts
type AnimFrame<S> = { state: S; note: string; counters?: Record<string, number> }
type VisualDef = { id, title, subject, view: 'bars'|'frames'|'lifeline'|'matrix'|'gantt'|'graph',
                   fields, defaults, variants: { id, label, build(input) => AnimFrame[] }[] }
```

通用 **MatrixView** 一次实现服务了银行家、KMP、IP 分片、流水线、Cache 五个动画。

### 已用可复算数值验证的硬指标（测试断言）

- **页面置换**（王道经典例题 / 3 块）：OPT **9** / FIFO **15** / LRU **12** 次缺页；**Belady 异常** `1 2 3 4 1 2 5 1 2 3 4 5` 用 FIFO 3 块 9 次 → 4 块 **10** 次；
- **进程调度**（P1 0/7、P2 2/4、P3 4/1、P4 5/4）：FCFS 平均周转 **8.75**、SJF **8**；
- **银行家算法**：安全序列 **P1→P3→P4→P0→P2**；Available 改 (1,1,0) 后判定**不安全**；
- **流水线时空图**：5 条指令 5 段，无冒险 **9** 拍 / 有转发 **10** 拍 / 无转发 **11** 拍；
- **KMP**：`ababaa` → next `0,1,1,2,3,4`、nextval `0,1,0,1,0,4`；
- **IP 分片**：4000 B / MTU 1500 → 3 片，偏移 **0/185/370**，MF 1/1/0；
- **Cache 直接映射**：`0,16,1024,16` → 命中 1 缺失 3；**图遍历**：DFS `A→B→C→F→E→D`、BFS `A→B→D→C→E→F`；
- **六种排序**：每步柱状图长度不变、最后一步必定升序；**内容自检**：卡/题/大题全部通过 `audit*()`。

### 冲刺模式

建议每天新学 = `ceil(没学过 / 剩余天数)`（夹在 5–80 张）；能否刷完 = `ceil(没学过 / 每日上限) ≤ 剩余天数`；
考前还能过几轮 = `floor(剩余天数 / 平均记忆稳定度)`；今日预计耗时 = 任务量 × 0.4 分钟。

## 已知取舍

- **包体**：构建按模块分块（katex / react / motion / dexie / marked / fsrs / content-* / index 共 13 个 js/css 分块），
  原始约 1.9 MB，gzip 约 640 KB，其中内容约 994 KB（gzip ~350 KB）。
  首次加载后由 Service Worker 永久缓存，之后离线秒开；改内容只让 content 块失效。
  若需进一步瘦身：可把 KaTeX 改为动态加载（省 ~78 KB gzip），或按"先加载本科目"做分段加载。
- 大题的评分点仍是**自评**（靠自觉），AI 批改排在 M5。
- 暂无账号与云同步：换设备靠「设置 → 导出/导入 JSON」（含卡片、题库、大题自评全部数据）。
